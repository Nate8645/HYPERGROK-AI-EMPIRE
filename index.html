HyperGrok – Devnet-Freigabe signieren

Nur Solana Devnet. Mainnet wird hart abgelehnt. Diese Seite sendet keine Transaktion. Öffne sie in Safari. Nach dem Verbinden kann Safari den zweiten Schritt (Signatur) blockieren, weil dafür ein Tipp nötig ist. Tippe dann Signatur in Phantom anfordern. Die Nachricht beginnt immer mit HyperGrok DEVNET TEST ONLY - NO LIVE TRADING AUTHORIZATION. Sie ist keine Live-Trading-Freigabe. Seed-Phrase oder privaten Schlüssel nirgends eingeben.

Netzwerk: devnet (fest, nicht änderbar)

Status

  1. Wallet-Verbindung gestartet
  2. Verbindung bestätigt
  3. Signatur angefordert
  4. Signatur erhalten
  5. Signatur geprüft (ed25519)

Noch nicht gestartet.

Signatur in Phantom anfordern

Falls Phantom mit -32603 / Unexpected error zurückkehrt

Zuerst in Phantom Testnet Mode einschalten: Profil-Avatar → Einstellungen → Developer Settings → Testnet Mode, Netzwerk Solana Devnet (offizielle Doku). Alle Varianten bleiben auf cluster=devnet — es gibt keinen Mainnet-Knopf. Tippe jeweils nur eine Variante und merke, welche (falls eine) funktioniert.

Ergebnis (an den Desk zurückgeben)

Prüfung auf der Box: Datei oder kopierten Text zurückgeben, dann npm run verify-signature -- signed.json. Das prüft nur die ed25519-Signatur (Test only). Kein Senden. Keine Live-Freigabe.
